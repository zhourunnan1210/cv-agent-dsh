## 假设

一句话写清「如果 X 成立，那么 Y 会提升」，并说明**为什么**（机制层面的理由）。
反面判据同样要写：什么样的结果会**否定**这个假设。

## 变量

| 类别 | 内容 |
| --- | --- |
| 自变量（我们改什么） | 例：频域分支的开关、损失权重 λ |
| 因变量（看什么指标） | 例：跨库 AUC（Celeb-DF / DFDC / DFDCP） |
| 控制变量（保持不变） | 例：训练集 FF++ c23、主干 XceptionNet、seed=42 |
| 对照 | baseline 与变体各自的 `config/*.yaml` |

## 成功判据

可判定的数字门槛，例：「在 Celeb-DF 上 AUC ≥ 基线的 +1.0，且 DFDC 不低于基线 0.5 以内」。
禁止写「效果更好」这类无法判定的判据。
